# Sat

Non-custodial Solana cüzdanı (Expo / React Native). Phantom'dan daha sade ve güzel bir arayüz hedefiyle geliştiriliyor.

> 🚧 **Geliştirme aşamasında.** Henüz gerçek cihazda test edilmedi, üretime hazır değil. Mainnet'te gerçek varlıklarla kullanmayın.

## Özellikler

- 12 kelimelik mnemonic ile cüzdan oluşturma / içe aktarma (BIP39, SLIP-10 ed25519, Phantom ile uyumlu türetme yolu)
- SOL ve SPL token bakiyeleri, gönderme/alma (Token-2022 dahil)
- Jupiter üzerinden komisyonsuz takas
- NFT görüntüleme
- Biyometrik kilit, güvenli anahtar saklama (SecureStore)

## Geliştirme

```bash
npm install
npx expo start
```

Detaylı mimari ve teknik notlar için `AGENTS.md` dosyasına bakın.
